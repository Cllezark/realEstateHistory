# Map Data Contract

The frontend consumes four static assets generated by Stage 12 of the ETL pipeline. All files are placed in `frontend/public/data/` and served as static files.

## Asset 1: tracts.geojson

GeoJSON FeatureCollection containing Census tract boundaries for the
South Pinellas & Gulf Beaches dashboard region (179 land tracts).

**Source**: 2020 TIGER/Line Census tracts, filtered by region membership
(centroid latitude ≤ 27.90, allowlist municipalities, or Clearwater Beach
island box). Tracts without qualified sales are still included and rendered
gray on the map.

**Projection**: WGS 84 (EPSG:4326)

### Feature Properties

| Field | Type | Description |
|-------|------|-------------|
| `tract_geoid` | string | 11-digit Census tract GEOID (e.g. `12103022701`) |
| `tract_name` | string | Human-readable tract label |
| `land_area` | number | Land area in square meters |
| `water_area` | number | Water area in square meters |

### Example

```json
{
  "type": "FeatureCollection",
  "features": [
    {
      "type": "Feature",
      "geometry": {
        "type": "Polygon",
        "coordinates": [[[-82.7, 27.8], ...]]
      },
      "properties": {
        "tract_geoid": "12103022701",
        "tract_name": "Census Tract 227.01",
        "land_area": 1234567.89,
        "water_area": 0
      }
    }
  ]
}
```

## Asset 2: tract-quarter.json

Quarterly market data indexed by quarter ID and tract GEOID.

**Structure**: `Record<QuarterId, Record<TractGeoId, TractQuarterRecord>>`

### Quarter ID Format

`YYYY-QN` where N is 1-4 (e.g. `2024-Q2`)

### TractQuarterRecord Fields

| Field | Type | Description |
|-------|------|-------------|
| `medianSalePrice` | number \| null | Median sale price (USD). Null when suppressed or no sales. |
| `qualifiedSaleCount` | number \| null | Number of qualified sales in quarter |
| `meanSalePrice` | number \| null | Mean sale price (USD) |
| `p25SalePrice` | number \| null | 25th percentile sale price (USD) |
| `p75SalePrice` | number \| null | 75th percentile sale price (USD) |
| `minSalePrice` | number \| null | Minimum sale price (USD) |
| `maxSalePrice` | number \| null | Maximum sale price (USD) |
| `averageRatePercent` | number \| null | Average 30-year fixed mortgage rate for the quarter (%) |
| `estimatedMonthlyPrincipalInterest` | number \| null | Estimated monthly P&I payment at average rate with 20% down |
| `hpi` | number \| null | FHFA Tract HPI index value |
| `annualChange` | number \| null | FHFA year-over-year HPI change (%) |
| `smallSampleFlag` | boolean | True when qualified_sale_count < 30 |
| `suppressMedian` | boolean | True when qualified_sale_count < 5 (median nulled) |
| `partialQuarterFlag` | boolean | True for the current incomplete quarter |

### Suppression Rules

- **Small sample** (`smallSampleFlag`): fewer than 30 qualified sales — flag displayed but values shown
- **Suppressed** (`suppressMedian`): fewer than 5 qualified sales — `medianSalePrice` and `meanSalePrice` are null. Other price percentiles may still be valid.
- **Partial quarter** (`partialQuarterFlag`): current incomplete quarter — all values present but flagged

### Example

```json
{
  "2024-Q2": {
    "12103022701": {
      "medianSalePrice": 450000,
      "qualifiedSaleCount": 12,
      "meanSalePrice": 465000,
      "p25SalePrice": 380000,
      "p75SalePrice": 520000,
      "minSalePrice": 320000,
      "maxSalePrice": 650000,
      "averageRatePercent": 6.87,
      "estimatedMonthlyPrincipalInterest": 2354.12,
      "hpi": 245.6,
      "annualChange": 4.2,
      "smallSampleFlag": true,
      "suppressMedian": false,
      "partialQuarterFlag": false
    }
  }
}
```

## Asset 3: metadata.json

Build metadata and configuration constants for the frontend.

### Fields

| Field | Type | Description |
|-------|------|-------------|
| `buildDate` | string | ISO 8601 timestamp of data generation |
| `dataSource` | string | Source identifier (currently `pcpao`) |
| `dateCoverageStart` | string | First quarter with data (`YYYY-QN`) |
| `dateCoverageEnd` | string | Last quarter with data (`YYYY-QN`) |
| `boundaryVintage` | string | Census boundary vintage year |
| `boundaryDescription` | string | Human-readable boundary description |
| `pipelineVersion` | string | ETL pipeline version |
| `smallSampleThreshold` | number | Threshold for small sample flag (< 30) |
| `suppressionThreshold` | number | Threshold for suppression (< 5) |
| `metrics` | string[] | List of available metric field names |
| `mortgageAssumptions` | object | Mortgage calculation assumptions |
| `attributions` | object | Data source attributions |

### Example

```json
{
  "buildDate": "2026-07-19T01:29:34-04:00",
  "dataSource": "pcpao",
  "dateCoverageStart": "2021-Q1",
  "dateCoverageEnd": "2026-Q4",
  "boundaryVintage": "2020",
  "boundaryDescription": "2020 TIGER/Line Census tracts",
  "pipelineVersion": "1.0.0",
  "smallSampleThreshold": 30,
  "suppressionThreshold": 5,
  "metrics": ["medianSalePrice", "meanSalePrice", ...],
  "mortgageAssumptions": {
    "downPaymentPercent": 20.0,
    "loanTermYears": 30,
    "paymentComponents": "principal_and_interest"
  },
  "attributions": {
    "hpi": "FHFA Tract HPI",
    "mortgageRate": "FRED / Freddie Mac 30-Year Fixed Rate Mortgage Average",
    "salesAndProperty": "Pinellas County Property Appraiser (PCPAO)"
  }
}
```

## Asset 4: parcel-sales.json

Individual property sale records, indexed by quarter ID and tract GEOID, powering the per-listing "Individual sales" panel.

**Structure**: `Record<QuarterId, Record<TractGeoId, ParcelSale[]>>`

### ParcelSale Fields

| Field | Type | Description |
|-------|------|-------------|
| `parcelNumber` | string \| null | PCPAO parcel number |
| `address` | string \| null | Site address |
| `salePrice` | number \| null | Sale price (USD) |
| `saleDate` | string \| null | Sale date, `YYYY-MM-DD` |
| `latitude` | number \| null | Parcel latitude |
| `longitude` | number \| null | Parcel longitude |
| `livingAreaSqft` | number \| null | Heated/cooled living area (sq ft) |
| `grossAreaSqft` | number \| null | Total building gross area (sq ft) |
| `parcelAreaSqft` | number \| null | Parcel/lot area (sq ft). **Derived** from `ACREAGE * 43560` — not a native PCPAO measurement. Null for records missing acreage or with acreage of exactly 0 (e.g. condo units, which have no individually-assessed land). |
| `pcpaoUrl` | string \| null | Deep link to the parcel's live record on the Pinellas County Property Appraiser site, built from its STRAP: `https://www.pcpao.gov/property-details?s={strap}` |

Null occurs for vacant land (no living/gross area) or missing source data, and should be omitted from display rather than rendered as `0`.

## Asset Generation

All four assets are generated by running:

```bash
python pipeline.py --stage publish
```

The publish stage reads from `output/dashboard_tract_quarter.parquet`, `output/dim_census_tract.parquet`, `output/fact_tract_hpi_annual.parquet`, and `output/fact_sale_enriched.parquet`, then outputs to `frontend/public/data/`.

**Note**: `--stage publish` alone only rebuilds JSON from already-computed parquet outputs. If a property-attribute field (like the three area fields above) was newly added to the canonical schema, stages 3 (`normalize_property`) through 12 (`publish`) must be re-run in order — a `publish`-only run will not pick up schema changes upstream of it. Run the full `python pipeline.py` after such a change.

Assets are deterministic: keys are sorted, formatting is consistent, and metadata is reproducible.
